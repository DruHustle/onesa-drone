# Maps

Routes use bounded local geographic projection and a procedural virtual campus.
No map SDK, tracking pixels, tiles or authoritative airspace feed is downloaded.
Coordinates are configurable internationally (latitude ±85°); this local model is
limited to a 3 km radius. Dateline and polar operations need a geodesic planner.
Synthetic restrictions are relative to home. Future licensed airspace/map adapters
must carry source, acquisition time, expiry and jurisdiction, independently of AI.
